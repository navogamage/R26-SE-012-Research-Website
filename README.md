# Black Pepper Research Academic Website

## Run locally

This is a static HTML, CSS and JavaScript website. No dependency installation or build step is required.

Open a terminal in this project folder and run:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Then open http://127.0.0.1:8000 in your browser. Keep the terminal running; press Ctrl+C to stop the server.

You can also open `index.html` directly in a browser or use VS Code's Live Server extension.
